# Winter — Largo (RV 297) — Antonio Vivaldi, "The Four Seasons" Op. 8 No. 4, mvt 2

Public domain composition. 18 bars, five aligned string parts collapsing to 3 MIDI
tracks (solo violin / pizzicato violins / viola+cello). ~52 BPM. Opening: E♭-major solo
(the source spells enharmonic D♯/A♯).

**PHASE-0 STUB.** Prototype build: `../../../music/winter.py`. Multi-part piece — vendor
one `.ly` per part here (`solo.ly`, `vln1.ly`, `vln2.ly`, `viola.ly`, `cello.ly`) in
Phase 1/2, transcribed from the prototype or re-typeset from Mutopia.
